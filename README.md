# USB to EtherCAT Adapter Board

## 📌 Project Overview

The **USB to EtherCAT Adapter Board** is a custom-designed PCB that provides an interface between a **USB host system and an EtherCAT industrial communication network**. The board is designed to enable USB connectivity on one side and EtherCAT communication through Ethernet interfaces on the other side.

The project focuses on the complete **PCB design and development workflow**, including schematic design, component selection, PCB layout, routing, Design Rule Check (DRC), Gerber generation, Bill of Materials (BOM), and 3D visualization.

## 🎯 Objectives

* To design a compact and reliable USB-to-EtherCAT interface board.
* To understand the hardware architecture required for EtherCAT communication.
* To design the schematic and PCB layout using **KiCad**.
* To practice high-speed signal routing and PCB design techniques.
* To generate manufacturing-ready **Gerber and drill files**.
* To verify the PCB design using DRC and 3D visualization.

## 🔧 Key Components

* **LAN9252I-ML** – EtherCAT Slave Controller
* **USB interface** – USB connectivity
* **RJ45 Ethernet connectors** – EtherCAT network interface
* **Power supply section** – Provides required power to the board
* **Crystal/Oscillator circuitry** – Provides clocking for the controller
* **Decoupling capacitors** – Power supply noise reduction
* **LED indicators** – Status indication
* Supporting resistors, capacitors, connectors and protection components

## 🛠️ Tools Used
